# Aprec - Estudio Jurídico

Sitio web profesional para un estudio jurídico, desarrollado con tecnologías web modernas.

## 📋 Descripción

Aprec es una plataforma web diseñada para presentar los servicios y la experiencia de un estudio jurídico. El proyecto proporciona una interfaz atractiva y funcional para que clientes potenciales conozcan los servicios legales ofrecidos.

## 🛠️ Tecnologías Utilizadas

- **SCSS** (46.4%) - Estilos y diseño responsivo
- **HTML** (36.5%) - Estructura y contenido
- **JavaScript** (17.1%) - Interactividad y funcionalidades dinámicas

## 📁 Estructura del Proyecto

```
Aprec-Estudio-Juridico/
├── index.html           # Página principal
├── styles/             # Archivos SCSS compilados
│   └── main.scss
├── scripts/            # Archivos JavaScript
│   └── main.js
├── assets/             # Imágenes y recursos
└── README.md          # Este archivo
```

## 🚀 Características

- Diseño responsivo y moderno
- Interfaz intuitiva
- Información clara sobre servicios jurídicos
- Contacto directo con el estudio

## 💻 Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a internet

## 📖 Cómo Usar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/mariawkpazcerpa-lang/Aprec-Estudio-Juridico.git
   ```

2. Navega a la carpeta del proyecto:
   ```bash
   cd Aprec-Estudio-Juridico
   ```

3. Abre el archivo `index.html` en tu navegador web
